# Inspiration Sources

Local addition (not from upstream). Use these when the brief has no reference signals,
or to check that a direction looks like real, current work rather than a template.
Browse them for direction; never copy a site's layout, copy or assets.

## SiteSee - https://sitesee.co
- Hand-picked gallery of modern websites.
- Filter by category (agency, app, event, game, informational, personal, product,
  publication, resource, service, shop) and by dominant color.
- Use it to: pick 2-3 real references for the page kind and color in the brief,
  then name what to borrow (type scale, grid, hero treatment, motion) in one line each.

## Varchive - https://varchive.ai
- AI news biased toward design, curated by Cameron Moll. RSS: https://varchive.ai/rss
- Covers AI design systems, agent design workflows and design-to-code tools.
- Use it to: check current practice before choosing a design system or tooling,
  not as a visual reference.
